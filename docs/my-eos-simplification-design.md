# My EOS simplification design

The **My EOS Dashboard** becomes the single personal Pulse home. Weekly preparation remains visible and actionable inside that dashboard rather than requiring a separate destination.

| Current source of confusion | Revised behavior |
|---|---|
| Weekly Prep is a separate page linked from My EOS. | A **Weekly preparation** section sits in My EOS. It uses the same saved fields and confirmation workflow but is arranged by L10 in the dashboard. The legacy URL redirects to My EOS. |
| Multiple creation prompts and generic work destinations create doubt about where an item lives. | My EOS has one **Add to an L10** composer. The person first selects an explicit L10 card; the selected L10 name remains visible above the item type and form. |
| “My Work” and “Personal” compete with meeting work. | Pulse V2 creation creates only L10-bound work. There is no personal or generic destination choice in the My EOS composer. |
| A creation prompt appears again below the work overview. | The dashboard has one creation surface only. Existing items keep their meeting label and open in their home L10 for fuller context. |

The composer uses direct action choices for **To-Do**, **Issue**, and **Rock**, not a type dropdown. It explains each type before creation and assigns the signed-in person by default. A To-Do has a due date, an Issue enters the selected L10’s IDS list, and a Rock requires a definition of done before it may be created. Each saved item remains in its selected L10 unless it is explicitly moved through the recorded routing flow.
